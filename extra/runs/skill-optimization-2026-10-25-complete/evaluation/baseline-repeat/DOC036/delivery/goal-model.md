# 目标模型

版本：v1。人工待审。

- 通过Instagram寻找并购买适合特定场合的礼物。
- 先查看服装设计，再到实体市场寻找类似款式。
- 按商品关键词及必要时的地点词找到当地供应商。
- 购物时避免给恶意账号付款却收不到商品。
- 联系商家时优先使用其公布的电话号码或WhatsApp以更快得到回应。
- 未确定礼物时浏览一个商家的多种产品图片，灵活发现可买的商品。
- 能够不登录就搜索、浏览应用中的所需信息。
- 临时查找购物信息时不希望别人知道自己在线。
- 能够复用过去搜索过的商家，减少重复查找。
- 借助商家产品的评论和点赞参与情况判断是否值得购买。
- 分享个人生活时让帖子仅被亲近朋友看见。
- 在线状态尽量只让亲近朋友看见。
- 即使丢失或更换电话号码，仍能通过Instagram重新联系朋友。
- 只在有实际需要时使用应用，避免受到无意识消费影响。
- 避免无限滚动和追逐他人动态耗费过多时间。
- 完成目的后能减少应用的日常可达性以控制使用。
- 初到陌生地区时快速了解商家的地点、联系方式和商品。
- 商家页面最好直接标出商品价格。
- 与商家确认价格、付款及地址后收到所购买的商品。
- 用产品发布时长与互动分布的合理性辅助识别可疑商家。
