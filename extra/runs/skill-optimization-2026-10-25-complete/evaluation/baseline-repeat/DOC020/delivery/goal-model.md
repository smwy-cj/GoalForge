# 目标模型

版本：v1。人工待审。

- 及时获知招聘邮件的新信息，避免错过求职消息。
- 通过邮件了解学校发布的新闻和通知。
- 用邮件办理牙医、诊所等预约。
- 通过邮件接收商家的促销和折扣信息。
- 偶尔通过邮件与朋友联系。
- 把待处理的重要邮件标记出来，方便有空时完成后续任务。
- 通过清理不再需要的邮件并区分重要与促销账户，使收件箱易于管理。
- 写信时能调整字体大小并加粗重要句子。
- 发送多媒体时尽量让收件人在手机和电脑上都容易查看。
- 避免重要邮件被误归为垃圾邮件，即使因此收到一些垃圾邮件也可接受。
- 发送后能够编辑邮件，让收件人优先看到新版，并可查看编辑历史。
- 能够可靠收到网站注册等本应送达的邮件。
- 内置AI助手能将简要要点组织成完整邮件。
- 邮件声称已附附件而实际未附时，在发送前提醒。
- AI助手能够提炼来信的主要内容。
- 突出邮件关键词和关键限制，降低遗漏重要细节的风险。
- 借助AI减少逐封阅读全部邮件所耗时间。
- 可以考虑定期汇总收到的多封邮件。
  适用条件：候选方案；具体频率和是否采纳尚未确定。
- 在重要消息识别足够可靠的前提下，收到重要邮件通知。
  适用条件：若可能漏掉重要消息，受访者不愿完全依赖自动识别。
- 紧迫截止日期下能够通过转发和群发让团队及时收到消息。
- 能够搜索邮件，并按标签或条件找到需要的邮件。
- 能够安排邮件在指定时间发送。
- 探索由通信双方自定义共同标识或类别，以区分招聘等邮件通信。
  适用条件：未来设想；实际可行性和采纳未知。
- 未来通过邮件与公司内外的人进行专业联系。
