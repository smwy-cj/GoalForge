# 目标模型

版本：v1。人工待审。

- 按具体话题获取信息，遇到技术问题时得到帮助。
- 获得针对自身问题、具有情境的个人经验和回答。
- 带着具体问题使用Reddit时找到答案并解决问题。
- 空闲浏览时寻找和阅读自己感兴趣的内容。
- 需要具体答案时比一般网页搜索更快找到有价值的信息。
- 通过在相关社区发帖寻求建议或问题解决方案。
- 移动端创建帖子中途离开时能保存草稿。
- 在移动端更容易跟踪评论和理解讨论线程。
- 改善安卓移动应用的响应速度和操作直观性。
- 购买产品前看到不同使用背景者较平衡的经验评价。
- 在Reddit了解一般健康知识时谨慎对待建议，不将具体健康问题完全托付给平台。
- 被动浏览时偏好卡片视图，主动检索时偏好紧凑视图以比较结果。
- 尽量获得不受广告干扰的阅读体验。
  适用条件：已有广告拦截时无需为去广告买会员；无法拦截时才考虑付费。
- 通过生成式AI工具按自己的问题找到最合适的具体社区。
- 在具体社区提问时获得更懂相关主题的人给出的较好回答。
- 改善官方移动应用，使其成为本系统有竞争力的使用选择。
