# 目标模型

版本：v1。人工待审。

- 在大学内即时联系想交流的人。
- 只知道姓名或姓氏时即可找到并联系大学成员，无需先存号码或邮箱。
- 能在手机或打开的电脑上方便地沟通。
- 通过频道迅速触达广泛受众。
- 加入频道后仍能读取加入之前的讨论信息。
- 了解课程、项目、院系和校园正在发生的事情。
- 与协作队友即时共享文档。
- 搜索过去消息和文件时更容易从大量匹配中找到所需内容。
- 更容易访问Slack的语音和视频通话功能。
- 与助教或教授需正式通信时，能够快捷跳转常用邮件应用发邮件。
  适用条件：用于适合正式邮件的情境，不要求所有Slack消息改发邮件。
- 尤其在群组中，让通话入口更容易访问。
- 个人并排打开多个窗口时，缩窄的Slack浏览器窗口仍易于导航。

## 需要确认

- 整组充分性尚未由原文确立；分析假设：联系人找到且附件已分享，对方离线或未回复时沟通目标仍未完全满足。
- 这组层级仍需确认，尚未作为成立的精化展示。
- 范围仅为本次提供的完整访谈；未证明业务需求穷尽。
- 目标资格、支持判断与精化判断由同一助手连续自检，未执行独立语义审查。
- 现有契约未单独表示障碍、偏好和辅助关系；关键条件保存在目标及引用中，不能声称完整结构化传递。

原文与层级依据可在 HTML 中展开。结构检查不等于语义证明，意见导出后交回助手。
