# 目标模型

版本：v1。人工待审。

- 找到价格、行程物流和灵活性适合自身情况的航班方案。
- 找到适合自己的航班行程。
- 找到适合自己的航班价格。
- 比较不同订票网站，找出最合适的选项组合。
- 尽可能提前约一个至一个半月订票，以获得更好的价格。
  适用条件：个人通常瞄准一个至一个半月；最近国内航班也会仅提前一两周。
- 为家人和朋友订票时利用剩余积分或礼券帮助他们节省费用。
- 在适合的旅行中尽量增加飞行体验并探访不同城市和休息室。
  适用条件：个人爱好；旅行可能疲劳，仍表示喜欢。
- 探索不同国家、地区、邻近机场和日期的航班组合。
- 使航班时刻与后续地面交通和住宿安排相衔接，避免无事等候很久。
- 现金订票的航班搜索通常尽量匿名，避免登录和个人数据被跟踪。
  适用条件：积分订票需要登录，是已声明例外。
- 积分订票时登录航空公司账户查看可用奖励座位并兑换。
- 在搜索中一次覆盖出发国或地区和目的国的多个机场。
- 需要衔接其他安排时将起飞与到达时间筛选到合适区间。
- 有总飞行时长上限时能筛去过长航程。
- 国际航班比较时兼顾价格与时间，国内航班通常优先看较便宜的选项。
- 核实各段航班、连接和时间是否符合自己的日程。
- 比较订票商评分、折扣和最终费用。
- 必须出行且票价突然上涨时，在几条候选路线降价时收到提醒。
- 同时搜索大量航班组合，减少研究所耗时间。
- 并行比较多机场、往返日期范围及不同舱位的组合。
- 在不熟悉当地票价时看到价格与市场中位水平的比较。
  适用条件：主要用于不熟悉的市场；熟悉后可能不需要。
- 行程尽量符合换乘交通和要会见者的日程。
- 尽可能获得夜间休息，同时可以接受红眼航班。
- 转机一般留出至少约1.5倍至2倍机场最短衔接时间以防延误。
  适用条件：签证问题会影响停站选择；时长随航段与机场变化。
- 在中转城市探访休息室前了解其是否开放。
- 理想情况下将持续更新的个人卡片休息室权益信息与航班搜索整合。
- 查休息室时确认对应航站楼、准入规则、开放时间及卡片剩余次数。
  适用条件：具体权威来源随发卡机构或通行证而定。
- 从聚合器进入所选订票商时保留已选择的航班行程资料。
- 能够在一处掌握订票研究需要的信息，减少访问多个网站。
- 若采用新平台，希望更快、更准确地研究更多航班组合。
