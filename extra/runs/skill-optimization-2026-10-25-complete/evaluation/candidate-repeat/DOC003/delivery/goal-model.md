# 目标模型

版本：v1。人工待审。

- 通过旅行网站找到符合自身情况的合适行程。
- 为所需行程找到合适的低价或优惠。
- 通常争取至少提前一到一个半月订票，理想为数月前，以获得更好价格。
- 也为家人和朋友预订航班。
- 用多余积分或礼券帮助亲友订票省钱并用掉余额。
- 个人旅行时偏好享受飞行和不同转机城市、休息室的体验。
- 在时间允许时跨多个网站、多个时段重复比较，以寻找更好的票价。
- 从国家或地区及附近机场范围搜索可行的出发地—目的地组合。
- 比较不同日期的可行航班组合。
- 选择与所需地面交通及住宿安排衔接的航班时间。
  适用条件：根据具体行程和可负担价差权衡，并不保证总能衔接。
- 比较多个预订供应商的最终价格、折扣及其他选项。
- 检查适用的优惠券或折扣，以确定更优惠的实际购票选项。
- 查看候选预订的升舱选项。
- 在购票前核对航站楼、航班连接及其他行程资料是否正确适用。
- 最终确定行程和供应商后，在供应商页面填写所需资料并用信用卡付款完成预订。
  适用条件：需要时填写护照、生日、法定姓名及声明；Skyscanner自身不完成订票。
- 现金购票的研究阶段通常不登录并尽量匿名，除非有特定迫切需要。
  适用条件：积分票需要登录航空公司；特定迫切场景可接受登录。
- 尽量减少向额外第三方分享个人资料。
- 积分订票时登录持有积分的航空公司网站查看候选行程的奖励座位可用性。
- 积分订票时直接在持有积分的航空公司账户完成奖励票预订。
- 通常用最便宜或最佳选项页比较候选航班。
  适用条件：国际行程更注重时间价格平衡；国内常看最便宜选项。
- 需要衔接其他安排时，按所需出发和到达时段过滤航班。
- 有明确飞行时长上限时，用时长过滤排除过长行程。
- 国际航班选择兼顾价格与总耗时的方案，避免只按最低价得到极长行程。
- 选择预订供应商时查看其评分。
- 候选行程不合适时，重新检查其他选项以免漏掉可用替代。
- 价差可承担时优先选择能赶上末班火车的航班以当晚到家。
  适用条件：仅该转机地面交通情境，受可负担价差约束。
- 必须成行且价格过高时，为几条可接受路线设置降价提醒，以便及时购票。
- 同时研究更多机场、日期、旅客及舱位组合以减少重复搜索。
- 比较现金与积分两类不同机制下的行程选择。
- 利用聚合器更灵活地发现适合自己的行程选项。
- 在不熟悉某航线市场时，查看票价相对常见或中位水平的比较。
  适用条件：仅不熟悉市场时的nice-to-have；不是必须每次查看。
- 探访他人时，使航班时间与对方日程匹配。
- 在可选择时优先保留夜间睡眠，同时可接受红眼航班。
- 转机时通常预留至少约1.5倍最低转机时间，并按延误风险倾向更宽余量。
  适用条件：签证问题仍影响可接受转机；不一般性限制经停次数。
- 计划转机时查看想去的机场休息室是否在该时段开放。
- 维持通过 Priority Pass 等方式在不同国家使用休息室的能力。
- 理想情况下由一个持续更新的服务记录持有哪些卡或通行证。
- 理想情况下按实际持卡和通行证情况获知可使用的休息室权益。
- 将可靠且更新的个人休息室权益服务与 Skyscanner 集成。
- 现有第三方信息更新不可靠时，从发卡方或通行证官方来源查休息室资料。
- 查询具体机场航站楼休息室的开放时间、准入政策及装修情况。
- 使用次数有限的卡时，确认它仍适用于该机场且在相关月、季或年周期有剩余次数。
- 获得可能提供适用优惠的预订合作方选项。
- 希望在一个地方获得做航班预订研究所需的信息。
- 希望能输入全部旅行参数后，由平台更便捷地找出合适选项。
- 在保持研究准确和覆盖组合的同时减少查找合适航班的时间。
