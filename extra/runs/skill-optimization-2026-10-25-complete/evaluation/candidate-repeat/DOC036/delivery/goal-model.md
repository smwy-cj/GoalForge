# 目标模型

版本：v1。人工待审。

- 借助 Instagram 为情人节等场合寻找并购买合适礼物。
- 先查看服装等产品设计，再在实体市场寻找喜欢的款式。
- 按商品关键词查找附近或指定地点的供应商账号。
  适用条件：受访者不确定是否自动利用位置；可手动追加位置关键词。
- 优先使用商家资料中指定的电话或 WhatsApp 联系，以更快得到回应。
- 避免向恶意商家付款后收不到所购产品。
- 遇到可疑卖家时要求先交付再付款。
  适用条件：受访者叙述可疑卖家场景；后续正常交易仍可能先付款。
- 没有具体商品打算时浏览同一商家的多种图片和产品以选择。
- 无需登录即可浏览和搜索商家等内容。
- 有时搜索商品时不让别人知道自己在线。
- 利用保存的搜索记录快速回到曾查找的商家。
- 查看产品的点赞和评论及其时间分布，辅助判断商家是否可疑。
  适用条件：这是个人判断线索，不是系统认证或可靠排名。
- 查看其他人的评论来判断产品是否适合作为礼物。
- 使用私密账号让发布内容仅供很亲近的朋友访问。
- 期望在线状态也仅对很亲近的朋友可见。
- 即使更换或丢失电话号码，也能通过 Instagram 重新联系朋友。
- 通过关注希望进一步了解的人保持联系。
- 只在有具体用途时使用 Instagram，减少无意识影响及耗时。
- 完成所需事项后通过退出登录等方式增加再次随手使用的阻力。
- 在节日购物期间暂时保持登录以便连续查看，结束后再退出。
- 到新地方或短期停留时快速了解商家位置、联系方式及所售产品。
- 希望商家在产品页面直接列出价格。
- 通过商家电话号码或 WhatsApp 询问所选产品价格。
- 确认购买后取得付款号码并支付商品款项。
- 付款后确认产品应送达的地址。
- 在商家通知到达后接收所购买的产品。
