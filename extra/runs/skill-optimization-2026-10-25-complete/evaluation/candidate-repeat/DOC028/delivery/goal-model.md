# 目标模型

版本：v1。人工待审。

- 通过相关 subreddit 和关键词获取所需主题的信息。
- 空闲时浏览关注的 subreddit，寻找有趣内容消磨时间。
- 遇到编程难题时在 Reddit 寻求技术帮助或其他解法。
- 针对当前问题获取更有针对性、贴合情境的个人经验。
- 有具体问题时，通过 Google 搜索问题并附加 Reddit 来直接找到帖子。
- 有预先定义的问题时，通过 Reddit 找到答案并解决该问题。
- 对读到的内容产生具体问题后，在 Reddit 进一步研究。
- 在有具体查询时更快找到可信的答案。
- 在合适的社区发帖寻求求学、职业或其他问题的建议。
- 可在相关帖子下新建评论或回复评论线程。
- 在发帖社区要求时为帖子添加适当标签以便相关人员筛选。
- 在手机上创作中断时也能保存帖子草稿。
- 在手机上更直观地查看和跟踪评论线程。
- 改善 Reddit 官方 Android 等移动应用的易用性。
- 偶尔通过关注社区了解相关时事和趋势。
- 购买产品前查看不同背景用户的评价，形成较平衡的预期。
- 用 Reddit 上的评价支持产品购买决定。
- 通过 Reddit 了解一般健康问题或入门锻炼建议。
  适用条件：不把Reddit当作具体健康问题的可靠诊断渠道。
- 被动休闲浏览时偏好卡片视图逐项滚动阅读。
- 主动搜索时偏好紧凑视图，以先看到更多相关结果再选择。
- 偏好无广告的阅读体验。
- 若无法使用广告拦截，则愿考虑购买 Premium 去除广告。
- 通过生成式 AI 描述所需主题，找到适合问题的具体 subreddit。
- 通过在更合适的专门社区发问，获得质量更好的回答。
  适用条件：回答可能仍差，不能完全消除。
- 改善 Android 版 Reddit 的运行流畅程度。
  适用条件：这是本人Android手机上的体验，未验证所有手机。
