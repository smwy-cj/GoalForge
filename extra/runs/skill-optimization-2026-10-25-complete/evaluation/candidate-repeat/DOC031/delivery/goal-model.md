# 目标模型

版本：v1。人工待审。

- 通过 Slack 与大学同学、助教及教授即时沟通。
- 仅凭姓名或姓氏找到校内联系人，无需事先保存号码或邮箱。
- 在手机或已打开的笔记本上联系校内人员。
- 借助频道即时向广泛受众传达信息。
- 加入频道后仍可查阅加入前的频道信息。
- 从频道了解课程、项目、院系和校园的动态。
- 协作时通过私信即时向队友共享文档。
- 通过关键词找到所需的过往消息或学习信息。
- 在信息量大的搜索结果中更容易找到所需消息。
- 让 Slack 的音频和视频通话更容易访问，尤其在群组场景。
- 已熟悉对方并持有其电话号码时，直接拨电话以更快联系。
  适用条件：认识对方且已有其电话号码。
- 需要正式联系助教或教授时，从 Slack 快速跳转到常用邮件应用发送邮件。
- 考虑改善浏览器窗口缩窄并排显示时的 Slack 导航。
