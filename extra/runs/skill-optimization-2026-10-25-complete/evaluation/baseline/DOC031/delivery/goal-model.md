# 目标模型

版本：v1。人工待审。

- 快速与校内同学、助教及教授沟通。
- 仅知道姓名或姓氏就能找到校内联系人，不必先保存电话或邮箱。
- 能够在手机和电脑上方便联系校内人员。
- 通过频道立即触达较广受众。
- 加入频道后可查阅加入前的历史信息，并了解课程、项目和校园动态。
- 与团队协作时能即时分享文档。
- 更容易从大量历史对话和文件搜索结果中找到所需内容。
- 让语音和视频通话更容易访问，尤其在群组中。
- 提供快速跳转常用邮件应用向指定联系人发正式邮件的功能。
  适用条件：需要与助教或教授等进行正式邮件沟通时。
- 改善缩窄浏览器窗口时的布局与导航，便于并排使用多个窗口。

## 需要确认

- 当前精化候选均有共同充分性缺口，仅供审核；未确认方案不展示为成立层级。
- 这组层级仍需确认，尚未作为成立的精化展示。
- 仅以所提供访谈全文为范围；未接触录音，native_text不等于人工核验。
- 提取、语义核验和模型复核均由当前生成方编制；独立语义审查、形式证明未运行，人工意见待审。
- 当前契约无独立障碍、贡献及偏好关系层；必要背景通过条件、推断、引文和问题承接，不声称完整传递全部关联语义。

原文与层级依据可在 HTML 中展开。结构检查不等于语义证明，意见导出后交回助手。
