# 隔离源文优先评审收尾

评审者为独立上下文模型评审者；清单与判断均不是人工 Gold，不表示需求已由人采纳。仅阅读指定原文、冻结清单及明确授权的首轮、第二轮匿名包，没有读取映射或生成分支。两轮 A/B 不假定对应同一方法。语言、粒度及解释模板仍可能使方法被猜测，因此为有限盲法。

8 篇文档、两轮、每轮两份模型均已逐项保存：各文档目录中的 `review-first.json` 与 `review-repeat.json`。共完成 516 项意图匹配、683 项目标判断、193 项联系判断、45 项组判断；每份模型对适用的冻结意图以及其全部目标、联系、组恰好核对一次。所有引用的目标 ID 均存在于对应匿名包，没有用其他包的 ID 补配。

`validation-first.json`、`validation-repeat.json` 记录逐项结构校验、包哈希和冻结清单未变的检查；`review-summary.json` 仅汇总判断类别的原始数量，没有计算标准 precision/recall/F1。冻结清单仍为 129 条，冻结 manifest 的 SHA256 为 `a740928558898d39b8ceb037bded2317d8063695f4dba7faef21641277076ecb`。

## 主要语义观察

- DOC003：多数模型保留价格、行程和隐私的情境权衡。首轮 A G013 将常规重查不合适行程也限缩至紧急无替代；第二轮 B G027 未保留“只有有限次卡才检查剩余额度”的条件。部分模型仅保留预填页面跳转，遗漏后续填写旅客资料及付款。首轮 B G032 将矩阵说明例子独立目标化，建议降回场景说明。
- DOC010：两轮基本保留普通早中晚三次与降雨频繁更新的区别。穿衣、随身物品、户外活动、交通方式等可以按不同粒度承接；没有仅凭多动词或节点多就认定混合或过拆。首轮 A G007 与既有普通频率、降雨例外条目有重复策略表达，单列了可合并问题。
- DOC013：不少模型未承接首次频道创建、付费无广告、具体播放器控制等原文范围；第二轮 B G006 保留了直播账户等待条件。播放器按钮一类主要是现场能力观察，目标性弱于明确 essential 的搜索、视觉浏览、流畅播放，缺失不能等权当主要意图遗漏。首轮 B G012 的等待不便表述较原文设问更强，单列修订。
- DOC020：主要防漏信、不对称垃圾邮件取舍、内置 AI、人工修改、附件提醒、关键限制突出与可靠通知均可找到证据。第二轮 A 缺少 AI 草稿后的人工调整承接；首轮 B G005 混合当前偶尔朋友联系与未来职业用途。首轮 A R001 把标记反向指向前序重要性识别，提出了关系方向修订。
- DOC023：应区分输入公司名和学校名、查看经历、筛选现任同校员工、通常介绍与可能内推请求。部分样本把所选关键词方式抽象成匹配结果，或把 maybe 请求升格。第二轮 B 明确保留请求语气差别，且其已 rejected 的 R008 按已否定联系评价，没有当作错误成立边。
- DOC031：即时共享的目的与私信的所选方式不是同一层含义；若仅写“共享文件”，仍可能丢失本人最常用的私信渠道。关键词检索也有类似结果级泛化。第二轮 B G007、G008 保留两项方式；其 R006 将姓名查找强连为每次共享的前序，证据只支持导航到个人页，已单列范围问题。
- DOC028：各样本基本保留具体社区发现的生成式 AI 方案及一般健康/具体健康的信任边界。Google 加 Reddit 的所选搜索路线、标签、表达能力、审核、视图排序、离线缓存等覆盖不齐。离线仅为现状描述且原清单标不确定，缺失不代表必须扩展。首轮 A G025、第二轮 B G016 有重复“官方移动应用更好”意图的粒度问题。第二轮 A R007 仅候选地把 Google 初始检索连向后续新问题研究，保持不确定，没有按已成立边处罚。
- DOC036：可疑商家先交货后付与正常订单先付后配送是不同情境，模型若保留条件不构成矛盾。跨商品年龄的互动启发式不是自动排名。部分样本遗漏送达前电话通知、购物期暂留登录或社交穿着带来的灵感。首轮 B R006、第二轮 B R011 有目标范围或因果方向不够贴合源文的问题，已逐项指出。

## 清单边界与后续解释

`errata-first.json` 与 `errata-repeat.json` 分别记录冻结清单未单列的明确次要意图、角色动作及弱目标边界，没有回写清单。例如剩余积分/礼券帮亲友省钱、维持 Priority Pass 准入、查看个人经历、读后新问题再研究、评论辅助挑礼物等，不能因未在冻结清单独立出现就把模型收录判为无依据。

所有组都按其实际 `proposed/partial` 状态评价：提出有依据的组织方案不等于声称充分；其正反场景若明确为分析假设，也未被误作访谈事实。联系是否有依据与一组目标是否充分分别核对。较粗或较细的结构均允许多对多承接，没有凭模型规模排序或据此给出采纳结论。

根侧已汇总并绑定逐项文件后，本评审不再覆盖这些文件。如后续发现必须修正的判断，应另存修订并通知根侧，保留当前评审字节版本。
