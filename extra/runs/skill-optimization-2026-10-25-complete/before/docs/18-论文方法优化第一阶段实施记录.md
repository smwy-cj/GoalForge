# 论文方法优化：第一阶段实施记录

2026-10-25。已完成仓库技能的兼容实现与工程验证，范围对应[方案](17-借鉴论文的Skills优化方案.md)第一批。真实资料重新生成、独立语义裁决、辅助关系 v2 和正式安装发布尚未执行，因此本次没有新的目标数、召回率或论文比较成绩。

## 已实现的改变

| 环节 | 现在的行为 | 主要位置 |
|---|---|---|
| 提取流程 | 局部候选捕获→全篇校正→语义拆合→覆盖回查；短材料可整篇读取；重复抽样按预算启用 | [提取入口](../skills/goal-extraction/SKILL.md)、[提取策略](../skills/goal-extraction/references/extraction-strategy.md) |
| 目标粒度 | 按可独立满足的结果拆分；目的、选定方式及不同条件不能只因相似合并；阅读摘要保留底层目标 | [目标边界](../skills/goal-extraction/references/goal-boundaries.md) |
| 分窗 | 支持 size/stride；保留轮次、说话者、原文、全局与窗口内字符位置；拒绝间隙参数、乱序或不符位置 | [源文工具](../skills/goal-extraction/scripts/prepare_source.py) |
| 候选去向 | 原始候选与最终目标分别保存；逐项 keep/merge/split/exclude/uncertain，pending 不伪装已完成 | [覆盖契约](../skills/goal-extraction/references/coverage-contract.md) |
| 覆盖检查 | 绑定源文、窗口、候选与最终目标文件哈希；检查遗漏处置、无来路目标、错误映射、引文位置及声明范围 | [覆盖工具](../skills/goal-extraction/scripts/check_coverage.py) |
| 配套复核 | 从重要原句逆向检查拆合/排除及条件；覆盖报告与模型检查分开，未执行不补造记录 | [复核入口](../skills/model-review/SKILL.md)、[语义复核](../skills/model-review/references/semantic-review.md) |
| 建模交接 | 维持原子目标和稳定 ID；覆盖检查不升级支持，实质改写仍返回提取核验 | [建模入口](../skills/goal-model-building/SKILL.md) |

增加三个版本化审计结构：goalforge-source-windows-1、goalforge-extraction-candidates-1、extraction-ledger-1。最终提取仍为 goalforge-extraction-3，模型仍为 goalforge-kaos-1。审计文件单独保存，现有模型组装器不消费它，也不会自动打包进交付附件。

覆盖检查的 structure=passed 只代表数据能核对，workflow=recorded 只代表实际提交的去向和声明范围记录完备；semantic_completeness 始终为 not_assessed。待确认项可以有记录而仍未解决，工具会单列它们。工具不会替助手提取、合并或编造支持结论。

## 验证结果

- 新增覆盖回归14项、窗口回归2项；连同已有源文4项，20项相关测试通过。
- 完整 Python 回归110项：受限环境首次109项通过，1项本机 HTTP 保存测试因 Windows 套接字权限10013受阻；该项在允许本机回环的执行环境单独复测通过。并非在同一次受限运行中全部通过。
- 三个正式技能通过 quick_validate；Windows 默认GBK读取失败后，使用UTF-8模式运行通过，没有修改校验器。
- 临时隔离安装验证提取技能可独立执行新覆盖命令，三技能原有交付及反馈流程仍通过；未修改全局或应用安装副本。
- 新最终目标可由现有 trace_candidates 核验及 KAOS 组装读取；合成测试不代表真实语义准确率。

## 使用方式与后续验收

实际命令和字段在[覆盖契约](../skills/goal-extraction/references/coverage-contract.md)。流程为 prepare_source 带窗口参数→capture-template→助手捕获并整理目标→template→填写实际运行与处置→check→现有语义核验与建模。旧记录和旧输出不覆盖；仅核验已有结果时不虚构分窗与候选生成历史。

下一项语义验收是冻结这一版技能，在方案列出的开发资料重新提取，检查一键全参数方案、可让步偏好、漏附件提醒、目的/手段及字符限制等是否忠实保留，同时防止把现有能力或含混回答升级成明确要求。这些开发答案未放入生产技能参考文件。本次工程测试没有完成上述真实语义验收，也没有将旧 output/output1 改写成新结果。
