# 目标模型

版本：v1。人工待审。

- Get a job.
- Improve coding skills that carry over to his daily work as a student and to work after joining a company.
- Be prepared for job interviews by practicing coding questions.
  适用条件：在多个平台上练习
- Practice primarily on LeetCode because companies draw interview questions, or variations, from it.
  适用条件：公司面试题来自 LeetCode 或其变体
- Practice interview-popular questions from NeetCode's concise, categorized list.
  适用条件：NeetCode 按类别整理题目
- Explore random or new questions on LeetCode to discover algorithms he has not learned.
- Consult GeeksforGeeks for step-by-step algorithm walkthroughs and more examples when LeetCode's explanations are unclear.
  适用条件：当 LeetCode 解法说明不够直观时
- Look up and practice the exact question a friend shares by its LeetCode number, so they can discuss the same problem and he is better prepared.
  适用条件：双方使用同一平台，按题号定位
- Complete all questions in a chosen category as a milestone, prioritizing categories he is not familiar with.
  适用条件：以 NeetCode 的类别清单为范围
- Practice coding questions daily while an interview is approaching.
  适用条件：面试临近时
- Keep coding skills from getting rusty by doing about two easy-to-medium questions as a refresher.
  适用条件：只想复习时
- Reserve a large, uninterrupted block of time for patient, distraction-free practice.
  适用条件：需要耐心且无干扰
- Target about 20–30 minutes for medium questions and 20–40 minutes for hard questions, with about 10 minutes for easy ones.
  适用条件：按平台标注的难度
- Measure his coding skill by timing each solve with the platform timer.
  适用条件：使用题目页计时器
- Practice more on a question category after exceeding the target time, so he can do better next time.
  适用条件：超过建议时间后
- Revisit previously solved questions later so he does not forget them.
  适用条件：首次解出之后
- Turn to the solution after about an hour of unsuccessful effort, then spend about an hour understanding and re-implementing it.
  适用条件：约一小时仍无法独立解出时
- Keep practicing similar questions in the same category through the linked similar-question button.
  适用条件：同一类别内
- Practice problems that are not yet marked as completed.
  适用条件：题目列表中没有完成勾选
- Avoid joining scheduled weekly contests while still practicing their problems.
  适用条件：仍使用竞赛题目练习，但不参赛
- Build the reading skill to reformulate unfamiliar weekly-contest wording into problem patterns he has practiced.
- Use weekly-contest problems as an additional measure of his coding skill.
- Track the number of completed questions to see improvement and gain confidence for interviews.
  适用条件：已有完成题目记录
- Have more test cases available from the start so he can code toward them and infer what is missing.
  适用条件：提交之前
- Allow other users to add custom test cases that serve as a reference while coding.
  适用条件：附加在现有测试用例上
- Show a recommended solve time for each question based on other users' experience.
  适用条件：按其他人的经验
- Avoid practice interruptions from the submit cooldown when correcting a small mistake after submitting.
  适用条件：提交后立刻发现小错误时
- Get performance feedback that consistently reflects code quality.
  适用条件：同一代码在不同时间提交
