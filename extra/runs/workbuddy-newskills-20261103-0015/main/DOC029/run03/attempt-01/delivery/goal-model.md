# 目标模型

版本：v1。人工待审。

- Present personalized content in a way that is tailored to the user's needs and current mood.
- Let the user start watching a movie with few clicks, including while the user is having a meal.
  适用条件：While the user is having a meal.
- Let the user resume a partially watched show at the exact point where they left off, showing how much of the episode is completed and the current timestamp.
  适用条件：Resume is offered from the Continue Watching carousel.
- Organize recommendations into genre-based carousels so the user can quickly pick something when in the mood for a specific genre.
  适用条件：Carousels are drawn from personalized content.
- Recommend shows similar to the one the user is viewing ('more like this'), offering multiple options so the user can choose.
  适用条件：Shown in the 'more info' modal of the title being viewed.
- Recommend titles saved in My List about one month before they are removed from Netflix, so the user can prioritize and watch them before they leave.
  适用条件：For titles saved in My List.；About one month before removal.
- Offer a carousel of selective 2-3 minute preview clips spanning genres, starting playback on hover, so an undecided user can judge whether a show suits them without leaving Netflix.
  适用条件：Presented as a recommendation carousel; a clip starts when the user hovers over a banner.；Clips last about 2-3 minutes and span genres such as funny, suspenseful and cliffhanger.
- Provide a play option on a preview clip so the user can jump directly to the full show.
  适用条件：After the user decides to watch the previewed show.
- Keep undecided users on Netflix instead of losing them to YouTube, reducing churn.
- Keep the software experience and the recommendation engine consistent over time so the service stays familiar to the user.
