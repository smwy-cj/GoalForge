# 目标模型

版本：v1。人工待审。

- Use the app to make quick small payments (called 'sell' payments, i.e. Zelle) to a few friends to split costs.
  适用条件：主要用途（'the main reason I use the app'）；转写中 'sell'/'cell' 为 Zelle 的 ASR 拼写，按 T006/T007 的定义校正；对象：几个朋友（T007 补充亲友）；小额、即时、凭手机号；主体为受访者本人
- Transfer surplus funds from the checking account to the savings account when the checking account has a lot of funds, in order to earn the small amount of interest.
  适用条件：条件：'when I have ... a lot of funds in my checking account'；强度：习惯性（'normally'）；预期结果：'get even that little bit of interest'；账户为本人名下的 checking 与 savings
- Use Apple Pay, which is connected directly to Chase, to pay at grocery stores and other outlets.
  适用条件：方式：Apple Pay 且'directly connects to chase itself'；场景：grocery stores / any outlets；习惯性用途
- Have the website provide a categorized data analysis of where money is spent (e.g. groceries or fuel) as a valuable insight for users.
  适用条件：软建议强度：'I think it would be great'、'I believe'；受访者不确定现有系统是否已按消费类别跟踪（'I'm not really sure if they ... track, what kind of expenses I do'）；T023：现有交易列表只按交易类型（card/Zelle/another fee/account transfer）分类，不按消费地点/类别；'data analysis'/'expense categories' 的措辞来自采访者 T020；'valuable insight for the users' 为受访者的推广性评价
- Be able to set and change spending limits on the debit card through the website.
  适用条件：强诉求：'something I'd really like to have'、'I would like to see that feature'、'honestly upset that they haven't added it'；仅针对网站端：T025 显示移动 app 可设置卡片参数/每日上限（且带 'I believe'），T035 确认网站端缺少专门选项；条件/例外：多数资金在未绑定借记卡的储蓄账户，故该限额当前不会触发；但'希望将来某时使用'，且曾在以前的信用卡/借记卡上用过；T028 的'每笔 100 美元'为采访者任务数值，不作为本目标内容
- Have Zelle implemented on the web app so the user does not have to reach for the phone every time.
  适用条件：诉求：'I would like to see them implement Zelle on the web app'；理由：更方便、'so that I don't have to reach my phone every time'；'My only concern is that it does not have Zelle'（T045）；T041：'I don't think we can ... sell [Zelle] on of the web app'，向他人转账需知道对方账号；背景：受访者平时用移动 app，本次首次使用网站（T012/T013）
- Have a chat/text-based support interface (chatting with a bank representative, or an AI bot) available on the website.
  适用条件：偏好/建议强度：'would be a great option'、'that'd be a great feature'，非强制；理由：比电话更放松、'not really anxiety inducing'、可一边发消息一边处理其他事；明确选定的方式之一：'through an AI bot'；尤其面向'people who don't exactly know how to get around the website'，可直接问 AI bot 并得到回复；信念/让步：'I believe there are a few limitations as to why they can't add it'；T053：网站现有替代方式为预约会议、发消息、找网点、打电话，无文字/聊天通道
- Make the more important (niche) features, such as locking/unlocking the debit card, more accessible with fewer clicks on the website.
  适用条件：诉求：'some of the more important features should be more accessible'；例证：为锁定/解锁借记卡'had to click like 7 or 8 times ... kind of bad design'；让步/条件：'I understand that because I don't think people use that as often'；总体：'I definitely don't feel better of the website'但'still stand by ... a very good ui'；主要功能（转账、查交易）'really good / accessible'；T035 另提'it's not very intuitive. I would really like it to be a bit more better'
- Be able to view all bank accounts, balances, deposits, withdrawals and recent transactions at a quick glance on the dashboard without going to multiple screens or extra clicks.
  适用条件：维持/避免型意图：'it's a good thing that I can ... look at all of my spends ... in a quick glance'、'don't really have to go to like multiple screens'；T015：登录后的 dashboard 展示所有账户、各账户余额、存款与取款；下方还有近期交易小列表，'pretty convenient'、无需再点链接/按钮；条件：在网站 dashboard 上（受访者首次使用网站）；张力：这是对已实现能力的正面评价，brief 4.3 提示'已实现能力不自动成为要求'，但维持/避免型意图应保留
