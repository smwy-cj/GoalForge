# 目标模型

版本：v1。人工待审。

- Reduce the number of steps needed to get course articles from the school portal onto the iPad so that the reading flow becomes seamless.
  适用条件：course material arrives as PDF links in the school (Canvas) portal；reading is done on an iPad rather than a computer
- Provide an export feature in the school web portal that sends course material to a single destination, such as Google Drive or the Kindle account.
  适用条件：the export starts from course or assignment links in the school portal；the destination is not finally decided: Google Drive, the Kindle account or a standalone application
- Make reading material in both ebook and PDF formats open in one single application so that reading is no longer scattered across many places.
  适用条件：at least for school course material；the application must handle both PDF and ebook formats；whether news websites are also in scope is not settled
- Let the existing Kindle app also manage PDFs so that both formats can be read in the same application.
  适用条件：offered as the easier option compared with a separate standalone application；the Kindle app currently cannot take the course PDFs
- Let students save valuable course PDFs into a personal library so the material remains accessible after the course or semester ends.
  适用条件：course material becomes unavailable once the course is over；also for later work use or re-reading
- Categorize and filter saved readings by time, such as month or year, so a reading can be found by when it was read.
  适用条件：applies to saved reading material；recalled by course and term, e.g. spring 2023
- Show the percentage of the current chapter that has been read, not only the overall percentage of the book, so that long chapters feel less daunting.
  适用条件：the existing Kindle app already shows time remaining in the chapter；percentage refers to progress within the chapter
- Provide a school online reading application in which articles sent by professors can be read directly on the student's iPad without downloading and uploading them.
  适用条件：school-owned application rather than an external service；proposal voiced as an idea, not a confirmed adoption
- Have the school's online reading application included for students rather than paid for separately.
  适用条件：asked directly whether he would pay for that application
