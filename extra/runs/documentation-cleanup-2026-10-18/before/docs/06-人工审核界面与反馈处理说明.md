# 人工审核界面与反馈处理

> 2026-10-18 更新：新版默认采用简明提取与 KAOS 层级模型，操作与输入输出见[新版审核说明](14-新版简明KAOS模型人工审核说明.md)。下文原分类、全对关系表、四输出和旧审核契约用于旧版；安装路径仍适用，安装时同步当前四项 Skill。

2026-10-16。四个Skill保持不变，最终HTML已从纯阅读扩展为可操作的审核工作台。主要由goal-model-building生成界面、model-review接收反馈，必要时交追溯或构建阶段处理。

从资料接入到最终归档的说明见[完整操作手册](07-完整流程操作手册.md)。原[审核报告](08-全流程审核报告.md)发现的问题已按[修复方案](09-审核问题修复方案与验证结果.md)处理；工具会同时传播目标与关系证据争议，并支持新判断回填和复检，人工认可仍需用户明确提交。

## 用户怎么操作

1. 打开最新goal-model.html，点击“开始审核”。默认优先展示推断目标、待确认事项及不确定关系；可切换全部目标、全部关系判断或全部证据。
2. 对照上方原表述、原句、情境和假设，在下方选择认可、修改、排除、合并、拆分或暂不确定。关系可改类型/方向/条件，证据可标记支持程度或引用错误。修改与争议需说明理由。
3. 点击“记录此项意见”。这会记录意见，模型本身尚未修改。下一项继续审核；也可撤回意见或放弃未完成表单。
4. “汇总与导出”可填写审核人名称和总体意见。未填写不等于认可；整体认可需明确确认完整范围和检查限制，存在修改、争议、待定或未完成表单时不能整体认可。
5. 随时“导出审核草稿”，下次用“导入审核文件”恢复；填写完成后点击“提交审核并导出”，下载review-feedback.json。需要可读留档时另导出review-feedback.md。
6. 把下载的JSON文件交回本对话，由助手校验并处理。HTML没有后台，“提交”指准备并下载反馈文件，不自动上传或写回原模型。

浏览器可以暂存草稿，保存失败会提示；不要仅依赖浏览器缓存。可靠的交接材料是导出的审核JSON。导入会先校验，只有用户明确点击替换才替换当前草稿，首版不合并多人意见。

审核人名称为自填，不是身份认证；当前工具适合单人本地审核，不提供多人协作账号、同步或电子签名。

## 修改怎么处理

| 意见 | 后续行为 |
|---|---|
| 单项认可、总体意见 | 保留实际意见、对象和版本；不推导整体认可 |
| 修改目标、排除、合并、拆分、补充有原文依据的目标 | 默认先形成计划；明确应用后由构建模块生成新版本，保留旧对象和来源映射 |
| 修改目标或证据存在争议 | 目标支持失效，交goal-tracing重新核对原文；争议不直接等于反证 |
| 修改关系或改变节点集合 | 重新评估受影响关系；未评估另列，不能填成无关系 |
| 暂不确定 | 保留待人工决定，不强行应用 |
| 整体认可 | 仅适用于被实际审阅且内容未改变的版本，核对明确确认和机械检查后登记 |

新版本使用.h1后缀和parent_version，changes保存原节点/关系、具体意见及处理去向。语义变更后的新版本人工状态回到pending，旧认可不继承。处理成功不等于证据支持已重新验证；需要追溯/关系重评时交付blocked草案和明确待办。

## 输入输出变化

| 阶段 | 新输入 | 新输出 |
|---|---|---|
| HTML人工审核 | 内嵌模型；可选旧审核文件 | review-feedback.json、可读MD；含未完成表单的草稿可保存恢复 |
| model-review反馈接收 | 模型、实际附件、submitted审核JSON | feedback-processing.json/.md，逐项记录去向；默认不改模型 |
| model-review应用反馈 | 相同输入，并明确执行应用 | feedback-model.json、反馈附件、复检JSON/MD、review-tasks.json；源文片段完整时有retrace-input.json |
| goal-model-building最终导出 | 修订模型、当前版本检查报告、实际反馈和证据 | 新版本JSON/MD/HTML/SVG及清单/附件 |

goal-extraction仅在反馈指出原文遗漏时补查；goal-tracing读取受影响新目标，沿用ID与版本绑定。技术文件由助手处理，用户不必填写字段。

## 已验证与边界

57项Python测试和7项JavaScript契约测试通过；实际浏览器验证了填写、记录、下载JSON、刷新恢复、合法文件校验与替换，以及过期反馈拒绝。桌面与390像素小屏已检查。实际下载的工程测试意见已跑过计划→副本应用→复检→四输出，原模型不变，新内容保留待追溯，未当作真实用户验收。

独立语义判断仍需助手/可用模型读取实际原件完成，未接自动模型API。人工审核不证明目标必然正确。HTML内嵌数据与资源，不向外部服务发送意见；本环境通过本地HTTP验证，直接file打开仍待允许该协议的用户浏览器验收。
