# 新版简明 KAOS 模型：人工审核说明

更新：2026-10-18。四项 Skill、新版工具与 HTML 已修改，等待用户审核。旧模型、反馈和交付保留。

## 打开这一份

[新版审核界面](http://127.0.0.1:8773/goal-model.html)，当前由本机预览提供，停止服务后需让助手重新启动。

离线文件：[goal-model.html](../runs/kaos-simple-v1/release/delivery/goal-model.html)。[简短文字版](../runs/kaos-simple-v1/release/delivery/goal-model.md)。

这是合成说明构成的 5 目标示例，用于审核层级表达、阅读和导出，不是 DOC023 的重新建模，不代表真实资料准确率。原文、判断和检查记录在交付目录，人工状态保持待审。页面里的测试意见已撤回。

## 你只需做四件事

1. 看目标是否简短、层级是否清楚。展开“下一级目标”；“各项都需满足”是共同条件，“任选一个完整方案”是替代路径。
2. 点目标文字，对照原文，选择“可以／需要修改／暂不确定”，必要时写意见并点击“保存意见”。
3. 子目标放错位置或不足以实现上层目标时，点“审核这组层级”。认可目标文字不等于认可层级关系。
4. 点“导出审核意见→保存文件”。本地预览返回文件实际保存路径，位置在本交付目录的 exports；将审核 JSON 附回对话，或明确告诉助手读取页面显示的路径。

可以只审一部分。未填写或未展开内容不自动当成认可，导出不直接改模型。整体补充可写在底部。

未完成表单先保存，或在“更多”保存草稿。下载异常时用“复制完整内容”粘贴给助手，或“查看文本”手动保存。独立 HTML 和普通静态预览没有本地写入回执，不把浏览器下载请求声称为文件已保存。

## 已精简的内容

- 目标不再要求主类、子类与分类理由；动作、困难、偏好按需作为依据或问题。
- 不再逐份推送候选、追溯报告、关系表和检查报告要求批准。
- KAOS 精化组替代默认全对关系表；没有依据时保留独立目标，不造树。
- HTML 默认可展开层级，原文与细节按需显示；分类统计与专业工具不占首屏。
- 默认 HTML、JSON、短 MD；SVG 在“更多→导出模型文件”按需取出。源文附件继续保留。

## 四项 Skill 输入与输出

| Skill | 输入 | 内部输出 | 用户默认看到 |
|---|---|---|---|
| goal-extraction | 原件、范围 | v3 目标 JSON、忠实转换稿和位置映射 | 单独提取或要求阶段审核时给短清单；完整流程继续 |
| goal-tracing | 当前目标、原文、绑定判断 | 位置与支持核对结果 | 目标旁的必要疑点，原文可展开 |
| goal-model-building | 简明目标、当前判断、精化包、必要反馈 | KAOS 模型、组、依据与版本 | HTML 主入口、短 MD；JSON 可取出、SVG 按需 |
| model-review | 模型、实际附件、用户意见 | 检查、受影响目标/组待办和记录 | 必要问题、短修改说明；新内容再审 |

用户不编制判断 JSON。助手依原文处理自然语言意见；程序不把任意意见自动变成已验证目标。
