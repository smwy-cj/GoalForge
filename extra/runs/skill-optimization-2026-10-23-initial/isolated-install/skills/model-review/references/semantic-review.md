# 语义复核与处置边界

目标资格沿用[目标边界](../../goal-extraction/references/goal-boundaries.md)，支持判断沿用[证据口径](../../goal-extraction/references/evidence-rules.md)，精化沿用[建模规则](../../goal-model-building/references/modeling-rules.md)。本文件定义检查视角，不维护另一套生成答案。

## 复核范围与分类

先复核全部精化组、争议关系和影响含义的问题，再按实际记录的资料/目标范围抽样其余内容；说明未查部分。一个对象可命中多类，分别记录，不把问题条目相加称为错误目标数。

| 类别 | 判断重点 | 处置 |
|---|---|---|
| 语义偏差 | 范围、强度、条件、主体或选定方式被改错 | 指出具体不支持部分，建议收窄并返回提取核验 |
| 来源与推断偏差 | 信念变事实、现状变明确要求、推断缺依据 | 保留合理意图，重判来源及完整支持范围 |
| 表达不足 | 基本忠实，但障碍关联、偏好或状态不清 | 补现有字段可承接的信息，不自动计语义错误；无法承接则记限制 |
| 候选遗漏风险 | 因偏好标签或已实现状态过滤维持意图 | 回查完整上下文和已有覆盖；未确认前不计真实漏提 |
| 精化问题 | 共同充分性、方案完整性、条件、假设或角色有误 | 仅重评受影响组，未解决时保留候选 |
| 正确/边界案例 | 避免、软目标或有条件偏好可能被误删 | 明确保留理由、成立条件和未知，防止修复引入退化 |

核对语义时检查问题、回答、后续解释与例外，不能只查引文位置。障碍与偏好不能被伪装为普通目标或父子边，负贡献不自动等于冲突。模型构造场景必须标明分析假设。

## 记录和修改权限

语义复核单独保存可读记录，每个问题使用稳定标识，记录目标/组引用、证据、类别、判断依据、建议、状态及后续处置理由。分项可以“已解决、未解决、不适用”，没有新证据时允许未知；不因进入最终交付就消失。本轮核心 issues 尚无稳定问题 ID/分类字段，不向旧契约静默添加字段；可读记录中的关键未决问题同时写入已有 questions/issues，说明这不是完整的结构化问题生命周期实现。

审核只修改结论、问题状态和真实反馈处置。实质改目标须交 goal-extraction，改精化交 goal-model-building，之后重核与重建；不静默改写或冒充用户采纳。候选遗漏尚未证实时不能为通过而补节点。

阻塞应说明具体对象、依赖组及可继续的范围。只有文件完整性、版本或全局解释不能保证时才把整份交付视为无法验证。当前工具 readiness=blocked 仍汇总任一 blocking 问题，因此报告须同时说明局部范围，不把汇总值解释成所有目标都错；不手改检查报告绕过现有规则。

## 证据层次与停止条件

分别报告脚本检查、生成方自检、后验语义评审、独立语义审查、形式证明、人工决定。记录实际执行者/上下文、可见材料和覆盖范围；没执行为 not_run，信息缺失为 unknown。另开调用不自动独立，结构通过不证明语义正确。

生成阶段隔离论文答案、development_reference、upstream_reference、裁决及比对报告；评审阶段如读取则注明证据角色。具体 DOC 编号及带答案的案例仅保留开发回归材料，不放入生成参考包。

有新证据或具体修订可解决问题时继续；同一未决判断重复且无新证据时记录限制并停止该问题的循环，继续可完成部分。
