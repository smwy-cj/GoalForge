# 冻结比对规则 v1

冻结日期：2026-10-22。阶段：先三篇开发试运行，再依同一规则处理其余文档。所有语义结论为 Codex 自动评审。

## 输入与比较单位

- 原文和本地产物以 input-manifest.json 的文件哈希为准；历史 DOC005 accepted 副本不重复计入 34 篇首版。
- 论文对照固定提交 16c4ce8bed513bbfdada7ac900ba6b718617a6eb，仅使用 study1/data1。
- 以 summarized.json 为论文建模前目标集：生成笔记本明确读取该文件，graphs.json 的 gN 节点对应其第 N 项。sampled-goals.json 属于另一阶段，另行留存，不混为同一目标集。
- 每篇论文的十个 graph 运行全部保留。图边为父目标→子目标。存在循环、未知节点和节点覆盖异常的运行单列，不能纳入有向无环图的闭包和深度统计。
- 论文 graphs.json 作为已公开图结构直接读取，不执行 models.json 或访谈者模型中的 Python 代码。models.json 和相关笔记本用于来源核对。
- 文档对应采用上游 ids 与本地 source JSON 的 upstream_id，源文逐轮核对；不以数组下标充当文档编号。

## 目标对应

- 输入一：本地目标的完整 statement、context、origin 及其引文；输入二：论文 summarized 中的原始英语目标；输入三：当前访谈。
- 一条本地目标可以对应多条论文目标，反之亦然，保留所有 ID。标签为 equivalent、local_broader、local_narrower、partial_overlap、local_only、uncertain；多项对应另标 split_merge。
- equivalent 要求主要意图、主体、适用范围和关键条件一致。抽象概括、数量限制缺失或不同强度不能仅因同主题标为等价。
- 没有对应的论文目标逐项记录为 paper_only；paper_only 不自动等于本地漏提，须区别原文支持、动作/功能描述、重复或无依据建议。
- 候选词面检索只能辅助查找，最终对应由 Codex 语义判断记录；不能将字符串或向量阈值冒充语义真值。
- 初期分别报告本地目标对应覆盖与论文目标被对应覆盖，均称参照对应率；不计算依赖完整独立 Gold 的提取准确率。
- 对支持不足、合理推断、条件缺失与当前能力描述的争议单列，不能把参考模型的所有目标当正确答案。

## 关系比较与精化

- 直接边与传递闭包分别计算。仅在 DAG 运行、成功对齐的明确节点对上作关系对应；未知/未对齐不自动计为负例。
- 多对多映射得到的投影关系只用于差异候选，不作为严格 precision/recall 的一一匹配样本。组充分性也不能由普通二元边自动推导。
- 论文宽泛 why/how 关系与当前 KAOS 完整精化组分开评价。已生成旧模型没有 refinement_groups，组充分性记未表达，不能默认通过或直接当语义错误。
- 不以边数、层数、连通率单独判优劣；记录有依据的层级、误连、漏连及无法确定项。
- 现有全部五条本地 refinement 必须回查；related/none 中的困难候选按实际查看范围报告，不声称未检查者已审查。

## 固定关系样本与复核

- 将论文固定关系样本测试与现有模型评分分开。采样和匿名化后先输出判断，再读取标签评分；共识标签、方向分歧和等价标签分开统计。
- 本会话已在准备阶段接触过少量标注示例及历史评价，不宣称全过程盲评。匿名顺序复判只作为一致性检查，不等于新的独立评审者。
- 校准规则和测试分组必须按 pair 的语义键隔离；若尚未做固定样本实验，指标写 not_run，不用自判关系数替代。
- 待确认与未评测分开。未判项不算错误也不算正确，所有指标显示分母和覆盖范围。

## PPT/KAOS rubric 与结论

- 检查上层目的与下层结果的可解释性、共同充分与完整替代、条件和假设、贡献/冲突与操作化的区分、场景覆盖及未决问题。
- 每项记 supported / partial / insufficient / not_applicable / not_assessed，并给源文或模型引用；不设加权总分。
- 按文档统计原始计数及分布，样本内关系不能当独立访谈。已接触数据仅作回顾性比较。
- 当前生成方的实际模型、预算和 skill 加载版本缺失则记 unknown；无法从产物差异推断 skill 的因果收益或成本优势。
- 第一轮语义评审看到了匿名目标以外的项目上下文，最终报告须披露这一局限。任何尚未执行的新上下文复判、人工审查或形式证明均保留 not_run。
