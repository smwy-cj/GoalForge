## PAPER summarized goals
g0 Ensure the system is simple and straightforward for users.
g1 Encourage widespread adoption by users to create a network effect.
g2 Allow users to search for friends or contacts by name.
g3 Enable users to explore and post social content.
g4 Allow friends to view posted stories or updates.
g5 Provide access to personal profile settings.
g6 Display a list of chats with contacts or groups, showing profile pictures, names, previews of latest messages, and timestamps.
g7 Provide a navigation bar with tabs for different sections.
g8 Allow users to view and search contacts to connect with friends, family, and colleagues.
g9 Enable choosing between private and group chats with a contact.
g10 Allow pinning or bookmarking of important chats and contacts for prioritization and easy access.
g11 Allow users to type and send messages.
g12 Automatically transfer and synchronize messages across devices.
g13 Store messages securely for access from multiple devices.
g14 Automate the backup and restore of messages for seamless device changes.
g15 Ensure continuous access to messages while minimizing device storage usage.
g16 Provide a way to manage messages effectively.
g17 Organize conversations effectively.
g18 Enable users to search for messages across all chats using keywords.
g19 Enable users to search for messages within a specific chat using keywords.
g20 Enable users to search for images from past messages using related text.
g21 Allow users to search for images using specific keywords.
g22 Enable users to bind their credit or debit cards for financial transactions.
g23 Allow users to make payments directly through the system for purchases.
g24 Facilitate money transfer between users and merchants.
g25 Provide a convenient alternative to cash or card payments.
g26 Enable users to initiate payments through multiple entry points on the interface.
g27 Provide users with a QR code for others to scan to initiate a payment transaction.
g28 Enable users to scan a QR code to complete a payment.
g29 Ensure users can confirm transactions before completing them.
g30 Authenticate users with biometrics for transaction confirmation.
g31 Facilitate the transfer of money upon successful authentication.
g32 Enable file transfer without size restrictions
g33 Enable file sharing
g34 Provide cloud storage for messages.
