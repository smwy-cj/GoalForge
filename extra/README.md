# 历史归档

本目录集中保存不参与日常使用的材料。此次只移动和保留历史文件，没有删除历史版本或覆盖失败记录。

| 目录 | 内容 |
|---|---|
| `docs` | 所有旧阶段说明、计划、比较与交付报告 |
| `runs` | 18个历史运行目录，含before快照、差异、失败、复核、截图和验收 |
| `output`、`output1` | 历史34篇398目标、后续559目标及其修订和审核附件 |
| `legacy-skills` | 已退役的goal-tracing转接目录；不再作为技能入口 |
| `legacy-tests` | 原迁移测试文件；其中仅针对旧入口的两个用例不再属于当前测试集 |
| `dist` | 历史发布包与整理后的当前技能快照包 |
| `cache` | 整理前的Python缓存，供完整追溯，不参与测试发现 |
| `tool-state`、`materials` | 旧工具记忆和教学PPT |
| `previous-root` | 整理前的根README |
| `organization-2026-10-26` | 本次移动清单、执行脚本、改动前文件及整理后验收 |

历史文件的状态、相对链接、绝对路径和“下一步”按其当时位置与日期理解。没有批量改写历史文件以免破坏既有哈希。查找搬迁前后路径请看[move-plan.json](organization-2026-10-26/move-plan.json)，每个移动项保存逐文件哈希；恢复时将destination移回source，先确认原位置无新文件，避免覆盖。

当前使用入口是[根README](../README.md)；完整工作过程见[全过程记录](../全过程记录.md)。不要从extra中挑一个旧SKILL或旧报告当作当前规范。
