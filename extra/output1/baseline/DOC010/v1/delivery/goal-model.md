# 目标模型

版本：v1。人工待审。

- 根据天气规划日常穿着、携带物品、户外活动和旅行。
- 日常外出前了解当天的天气，以决定穿着和携带物品。
  适用条件：日常外出前；包括早晨准备和再次出门
- 计划旅行时，在购买户外活动门票前了解目的地一周天气，以安排活动。
  适用条件：旅行规划，尤其未到过的目的地；购买活动门票前；旅行时看一周，平时按天看
- 到不熟悉的地方时，借助天气应用熟悉当地天气状况。
  适用条件：新地点或尚不熟悉当地天气时；长期居住且熟悉的地方未必需要同样频繁查询
- 收到雷暴、洪水等极端天气的通知或警报，以便推迟活动并避免外出。
  适用条件：雷暴、洪水等极端天气
- 常规天气通知每天早晨、下午和晚上各一次，以融入通常外出的日程。
  适用条件：常规天气；降雨时另有频繁通知偏好
- 持续降雨时，更频繁地收到降雨开始、停止及变化的通知。
  适用条件：持续降雨或不利天气情境；区别于常规每天三次通知
- 获得实时天气更新，帮助在外出时决定步行还是乘车等安排。
  适用条件：外出安排，尤其临近降雨时；受访者承认技术对天气预测仍有限制
- 天气信息在应用、网站及其他使用的平台之间保持一致。
  适用条件：相同天气情境下比较应用和网站等平台
- 使用天气应用时不受广告打扰。
  适用条件：受访者提到未订阅时随机广告的体验
