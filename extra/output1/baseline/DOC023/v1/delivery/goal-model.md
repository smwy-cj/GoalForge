# 目标模型

版本：v1。人工待审。

- 增加LinkedIn个人档案上的人脉连接数量。
- 通过个人档案向他人展示自己在LinkedIn上活跃。
  适用条件：受访者认为连接数量可作为活跃的展示信号
- 获得目标公司的现任员工为实习或全职岗位提供内推。
  适用条件：求职竞争较强；希望申请目标公司的岗位；受访者认为该公司现任员工才可为所申请岗位内推
- 借助内推提高简历被招聘人员看到的机会。
  适用条件：实习和全职岗位申请
- 寻找并选择同时是目标公司现任员工和本校校友的潜在人脉，以提高获得内推的可能性。
  适用条件：为特定公司岗位寻找内推人；当前公司任职和同校背景两条件共同适用；不会选择仅曾任职而不能内推的人
- 搜索结果更准确地匹配所需潜在人脉的背景，减少逐个排除不匹配结果的负担。
  适用条件：寻找符合公司与学校背景要求的潜在人脉
- 能够查看足够多的潜在人脉，以找到符合需要的联系对象。
  适用条件：非会员可见结果有限，严重时合适者只有一两个或没有；购买Premium可扩大可见范围，但受访者认为费用高
- 连接邀请获接受前，能够在附言中充分表达自我介绍和内推意图，减少压缩措辞的时间。
  适用条件：对方接受连接前的邀请附言；受访者描述非会员200字符限制；内推请求有时在附言中提出
