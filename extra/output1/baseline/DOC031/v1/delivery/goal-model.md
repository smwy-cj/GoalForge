# 目标模型

版本：v1。人工待审。

- 通过Slack与大学内的同学、助教和教授即时沟通。
  适用条件：大学内部日常沟通
- 只知道姓名或姓氏即可找到并联系校内人员，无需预先保存电话或邮箱，手机和笔记本上均能使用。
  适用条件：Slack校内社区中可访问的人员；已知姓名或有时仅知道姓氏
- 通过频道迅速向较广的受众传达信息。
  适用条件：频道内的群体沟通
- 加入频道后可查看加入前的历史信息，并了解课程、项目、院系和校园的讨论动态。
  适用条件：加入相关频道后，包括加入之前已有的信息
- 与队友协作时，即时分享所需文档。
  适用条件：与队友协作，通过直接消息分享文档
- 搜索大量频道历史时，更容易找到自己需要的特定消息。
  适用条件：用关键词查找既往课程讨论等信息；不知道精确目标时，过多结果使查找困难
- 更方便、快速地进入语音或视频通话，尤其是群组通话。
  适用条件：Slack通话入口当前需要跨窗口导航；尤其群组场景；熟识且有电话号码时可能直接打电话
- 正式联系助教或教授时，能从Slack快捷跳转到Outlook、Gmail等邮件应用给对方发邮件。
  适用条件：需要正式邮件沟通的情境；使用标准邮件应用，不限定单一提供商
- 多个窗口并排、Slack浏览器窗口缩小时，仍能方便地导航。
  适用条件：受访者习惯多窗口同时打开并排，举例为三个窗口；手机和约14英寸大屏体验原本较好
