# 目标模型

版本：v1。人工待审。

- 在忙碌或补充固定日用品时，通过线上买菜节省购物时间
- 搜索并加入购物车的商品应属于所选本地Whole Foods，避免结账时重搜
  适用条件：跨Amazon与Whole Foods搜索时，图标易错过；两个结账清单是现有缓解措施
- 能用搜索直接找到已知品牌和规格的指定商品
- 根据过去订单建议所需购物清单
- 保存并复用可定制的购物清单模板，例如日常和聚会清单
- 定期展示待购清单，经本人确认后才下单并安排自提
  适用条件：提议约每两周提醒；是否已有该功能尚不确定
- 减少反复输入和重建购物清单，并减少遗忘商品后的补跑
- 根据本人使用方式推荐可能有用但尚未发现的功能
- 购买时清楚查看品牌、价格及商品数量
  适用条件：尤其需要区分一袋与多袋等包装数量
- 购买可能含坚果的食品时能查看配料表以判断是否适合自己的过敏情况
  适用条件：例如新鲜布朗尼；配料表是否总可用受访者不确定
- 线上买菜以高效采购为主，通常不花时间随机探索新品
  适用条件：需要探索时更偏好实体店；偶尔在线浏览零食品类仍可接受
- 偶尔按零食品类浏览时，可考虑提供类似信息流的推荐
  适用条件：仅偶尔零食探索；不要求默认强推或挤占定向采购
- 商品缺货时可按商品选择指定替代品、接受店员最接近替代，或不替换
  适用条件：意面可较宽松；特定配方或昂贵商品可能拒替
- 对特定配方所需或价格较高的商品，缺货时可以拒绝不合适的替换
- 优先选择附近门店自提，在节省逛店时间的同时避免配送费用
  适用条件：住得近时的个人偏好，不排斥配送
- 希望了解线上与线下购买数据被如何关联和使用
  适用条件：从未深入账户设置；实体与线上数据共享是受访者的理解
