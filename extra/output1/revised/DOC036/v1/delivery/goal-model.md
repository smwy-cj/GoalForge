# 目标模型

版本：v1。人工待审。

- 在情人节等特殊场合为亲近的人选购合适礼物，例如女友喜欢的蛋糕
  适用条件：当前下单流程是联系商家问价、确认付款号码和地址，支付后等派送/到达电话取货（T058）；此为报告的做法，不逐一新增强制产品能力。
- 来到陌生地点或短暂停留时，快速找到当地商家的位置、联系方式及所售商品
  适用条件：使用源于方便，不是明确优于所有替代品；地点和商品信息真实与否未核验。
- 按想买的商品类别搜索商家，需要时补充地点词以找到相关本地店铺
  适用条件：本人不确定系统是否集成本地定位；结果主要是商家账号，而非像商品电商直接交易。
- 还没确定具体商品时，浏览商家的多种商品图像，从现有选择中灵活挑选
- 可以先在线查看服装款式，再去实体市场寻找看中的设计
  适用条件：线上浏览可启发线下购买，不强制通过平台完成支付。
- 联系商家时偏好使用其公开指定的号码，通过电话或WhatsApp更快沟通；应用内聊天也可选
  适用条件：活跃账号有时回复很快；不预期商家一直在线。
- 尽量避免向恶意商家付款后收不到商品，减少购物损失
  适用条件：他说那次没有损失钱；商家确属恶意为受访者判断，未作外部核实。
- 查看商品评论、点赞及其随发布时间的分布，作为辨别可疑商家和辅助选购的线索
  适用条件：互动相似或过少被本人视为可疑，是经验性判断；真实商家也可能少互动，恶意商家也可能伪造互动。
- 无需登录也能浏览、搜索并查看商家资料，方便快速查找所需商品
  适用条件：当前会暂时留登录来完成节日前购物，是应对不便的策略而非偏好强制登录。
- 只想快速查购物信息时有时不让人知道自己在线；社交使用时希望在线状态仅亲近朋友可见
- 分享私人生活内容时保留私密账号，使帖子仅亲近朋友可见、公众无法查看
  适用条件：担忧公开生活内容可能日后伤害自己为本人风险信念，不当已证必然后果。
- 从保存的历史搜索中选回用过的商家，减少再次查找
- 更换国家、号码或失去直接联系方式后，仍能通过平台与朋友重新联系
- 仅在有需要时使用平台，并通过用后退出、移除应用等方式控制耗时和无意识消费影响
  适用条件：有购物节需要时可提前几天开始浏览并暂留登录，用完再退出；卸载、网页清历史是当前策略而非平台强制流程。；无限滚动与追赶他人动态被描述为耗时/成瘾因素；服装社交影响可能促进消费但本人对此有保留。
- 希望商家商品页面直接显示价格，减少先联系询价的需要
  适用条件：猜测商家希望收到询价反馈不是已验证商业动机。
- 面对可疑商家时要求先交货再付款，避免那次可疑交易的预付损失
- 希望能够匿名发帖
  适用条件：仅由采访者并列归纳与简短应答形成待确认候选；不当已确认需求，也不用作成立精化前提。
