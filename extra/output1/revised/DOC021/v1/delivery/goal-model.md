# 目标模型

版本：v1。人工待审。

- 搬往新地区或国家时找到适合居住的房源
- 先找到目标地区常用的房源网站，了解当地可选房源及价格范围
  适用条件：可能参考当地人建议；网站选择不等于保证真实。
- 按预算、面积或卧室数筛选房源，有特定工作或学校时通常选择附近地区
  适用条件：设施、附加功能和外观为次要进一步取舍，未设权重。
- 通过沟通获得足够信息并根据回复情况进一步判断和缩小房源选择
  适用条件：可转用电话、邮件或房源自己网站；平台主要用于发现。
- 希望房源信息保持最新，并能看到最后更新时间
  适用条件：详情现有地址、照片、户型、价格、单位数量和设施等本人觉得充分，主要缺更新时间。
- 联系房源前后能清楚看到流程、下一步及预计回复时间，增强使用信任
  适用条件：可用小时间线等视觉方式；一周至一月为常见决策窗口，不设所有人最大等待。
- 可以考虑像电商选择现有选项一样，直接选择已列规格的感兴趣房源，减少尚未确定需求时的精确填写
  适用条件：咨询时需求可能灵活，还未确定卧室、浴室和日期；类似加入购物车是选择概念。
- 双方确认房源可用且有意继续后再分享个人资料，避免向所有感兴趣选项预先交出大量信息
  适用条件：房源先表明可用，自己感兴趣，双方确认继续后才可能分享。
- 希望仍可用地图画定搜索区域，更灵活地包含邻近合适房源
  适用条件：2米邻近为例示，不作固定半径。
- 查看住过房源者的评价，汇集信息并帮助建立信任
- 将几个感兴趣房源集中在一页，同时比较主要特征
- 收藏房源后能在导航栏或至少菜单第一层找到保存项
  适用条件：收藏用于保存感兴趣房源，常与比较联系。
- 不强制注册或登录即可搜索、查看信息并与房源方沟通，注册可供自愿保存或预填资料
  适用条件：本人认为无必要个性化是其信念；非已证架构不能需要账户。
- 保留可选的筛选项，不强迫在需求尚不确定时填写所有条件
- 筛选如宠物政策时可选择同时包含明确允许与未填写者，或仅显示明确允许者
  适用条件：可考虑增加“包含未说明”复选框；不包含明确不允许的选项。
- 可以考虑要求房源照片采用特定拍摄规范，以更可信地呈现房源
  适用条件：担心差照片误弃好房或照片优于真实；可信度效果未知。
- 若沟通过程清楚且快捷，希望在单一平台内完成房源沟通
  适用条件：当前因为平台过程不清会用电话邮件，未知回复速度是体验不透明，不必然房源方慢。
- 希望通过更透明的信息和流程，更安心、有信任地继续参与选房过程
  适用条件：更新时间和小时间线是本人提出的因素，不保证全部欺诈风险消失。
