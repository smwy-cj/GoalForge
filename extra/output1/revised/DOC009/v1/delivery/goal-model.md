# 目标模型

版本：v1。人工待审。

- 使用AI助手提高工作效率并节约时间
- 获得简洁直接的回答，优先于冗长的对话式回应
  适用条件：目的为生产力与时间；没有长度阈值。
- 助手保留以往交互的相关背景和要求，避免每个查询或新对话都重复解释
- 通过少量提示撰写适合专业场合的邮件
  适用条件：主要专业邮件，少量个人邮件；不要求所有社交消息AI代写。
- 为工作和允许使用AI的作业构思不同想法，并更好表达自己的想法
  适用条件：作业仅限允许使用AI者；也用于工作长文。
- 检查本人写作文档的拼写、语法及语气
- 更快生成可嵌入博客和社交媒体帖文的数字艺术
- 编程任务可输入和输出所需的JSON、XML等标准格式
  适用条件：除自然语言外；格式示例未穷尽且并非所有任务都强制结构化。
- 保留文本框加相关附件的交互方式
- 可以考虑直接通过语音提供提示
- 减少AI回答中事实不准确的内容，使其更可靠
- 当前关键任务中保留人工核查AI生成内容的环节
  适用条件：基于当前不完全可靠性的个人判断；不能直接开箱自动化关键任务。
- 在内容可靠性允许时将更多任务管线自动完成以进一步提高生产力
  适用条件：目前还需要人工内容核查；没有给出幻觉检测解决方案或安全阈值。
- 解数学题时用多个助手交叉核对答案
  适用条件：数学题情境；多助手一致不被当作数学正确性证明。
- 使用时界面少些干扰并便于自己操作
- 希望助手增加从文本生成视频的能力
- 希望描述任务后助手能实际操作应用完成任务，例如打开邮件客户端、撰写并发送邮件
  适用条件：建议/未来方向；未说明代理授权、确认、失败和恢复界限。
