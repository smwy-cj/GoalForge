# 目标模型

版本：v1。人工待审。

- 通过背景音乐缓解现实生活压力并感觉生活仍在继续
  适用条件：考试或压力大时听得较少，但仍需要背景声音。
- 尽量有声音在背景播放，以避免难以适应的安静
- 按当下需要播放熟悉的歌单，并使用随机播放及整单循环
  适用条件：约七成使用为此方式，其余使用会搜索新曲。
- 通过情绪或关键词搜索公共歌单，找到贴合当前感受的歌
  适用条件：感到特定情绪时。
- 为脑中舞蹈等创作构想寻找匹配歌曲并获得灵感
  适用条件：通过关键词试听不同歌单和歌曲，是否获得灵感未保证。
- 听到感兴趣的歌曲片段后找到完整歌曲，并继续发现相似且喜欢的新歌
  适用条件：也会在原歌单收听期间想听新歌。
- 保留适合自己口味的个性化歌单，以更容易找到更多喜欢的歌曲
  适用条件：包括当前常听、昔日喜爱、日常及相似歌手混合；口味会随时间改变。
- 睡前可按歌曲结束或所选时长停止播放音乐
  适用条件：睡前使用，原文时间为选项示例。
- 能创建便于他人查看的共享歌单，并保留一起听歌的社交选项
  适用条件：关于Apple Music缺失的判断仅为过去使用经验，当前是否更新本人未知。
- 保留可收听的优质环境声音内容
  适用条件：有时听环境声音；音乐内容还包含电影、音乐剧和独立艺术家作品。
- 希望首页展示普通用户创建并受欢迎的公共精选歌单
  适用条件：主要动机是不同视角，社交只是兼有作用。
- 可以考虑根据相近听歌者推荐他们听的歌单，以获得不同的人类视角
  适用条件：建议是否有效未确定，不代表已采纳或技术可行性已证。
- 在主要平台找不到特定混音时仍能通过其他平台听到它
