# 目标模型

版本：v1。人工待审。

- 进行长期财务规划，为未来退休储蓄。
  适用条件：个人长期目标，不表示交易必然实现储蓄收益。
- 在投资过程中提高金融素养并理解市场及获利算法。
  适用条件：次要目标；受访者曾通过学院学习，不要求任一平台内容自动成为权威投资建议。
- 提高金融算法方面的知识，以帮助未来求职。
  适用条件：第三层个人目标；未承诺特定岗位或就业结果。
- 希望获得进阶交易算法以及期货、期权的更深入学习指导。
  适用条件：本人回忆过去学院入门为主，不确定现在是否已改善；建议增补。
- 让开户及银行账户绑定尽可能简单顺畅。
  适用条件：印度使用背景；账户验证是已述流程；不推导取消必要验证或绕过法规。
- 以更少时间和操作努力顺畅完成交易。
  适用条件：所述监管和地域差异是其体验/理解；无具体时延阈值。
- 希望能在银行现金与拟投资加密货币之间方便地转换资金。
  适用条件：谈及当时印度Coinbase体验；银行整合或支付界面是可选实现，不表示当前产品事实。
- 了解目标股票的当前变动，以支持交易判断。
  适用条件：本人常在每天收尾查看；不要求所有品种持续盯盘。
- 需要时能够即时下单交易。
  适用条件：由本人决策；即时是体验用语，没有量化成交时限；下单不等于保证成交。
- 能够设置交易规则。
  适用条件：作为即时手动交易之外的可用选择；规则内容与执行权限待定。
- 在应用内通过独立金融新闻界面了解可能影响持仓的市场事件。
  适用条件：当时外看新闻；其他应用红绿情绪标记是描述，未要求照搬或相信其预测。
- 继续在一个组合页面了解当日投资涨跌及整体盈亏。
  适用条件：每天查看，约半月/月调整长期投资；不把现有四项订单字段转为完整强制规格。
- 保留对感兴趣股票的观察清单，以便后续考虑投资。
  适用条件：并不频繁用，但会追踪少量兴趣股票；个人维持意图。
- 可考虑增加共同基金投资选项。
  适用条件：本人不确定可行性或平台定位；认为比单股安全是其信念，不作事实保证。
- 如可行，希望能用语音下单。
  适用条件：提出新增功能；本人不确定可行性；未授权系统实际执行任何交易。
- 如可行，希望通过语音获得所需投资信息摘要。
  适用条件：与语音下单是不同候选用途；未指定总是朗读或访问全部数据。
- 减少为查询投资信息反复进入应用的负担。
  适用条件：需要随时查询时；未要求完全不打开应用。
- 更倾向沿用已配置的投资系统，除非新应用提供不可或缺的显著功能。
  适用条件：换用意愿约1或2；原因是重建系统耗时；不是禁止迁移或反对全部新应用。
- 加密投资更倾向少量投入所熟悉的主流币，以控制自己能承受的风险。
  适用条件：股票投入较多；担忧波动和诈骗币；认为热门币较安全是个人信念，同时接受可能全部损失。
