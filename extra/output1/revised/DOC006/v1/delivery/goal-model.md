# 目标模型

版本：v1。人工待审。

- 浏览日常资讯以免错过重要事件和新的招聘信息
- 持续获得符合个人兴趣的最新内容推荐
- 能从首页浏览信息并找到感兴趣的帖子
- 能通过每日新闻热度排行选择要阅读的新闻
- 通过搜索词检索所需信息
- 搜索租房等信息时可按城市或地区缩小结果范围
  适用条件：主要例子为租房；T015确认希望有搜索条件
- 尽量通过免费的社交平台查找租房信息
  适用条件：寻找租房信息时的个人成本偏好
- 求职时了解已有多少人进入招聘流程，以判断公司的招聘规模
- 求职时获得近期应聘者的面试反馈，以判断面试门槛
- 在不想看娱乐内容时，将其从求职、租房等实用信息中筛除
  适用条件：仅在用户不想看娱乐内容时
- 也能使用社交应用获取日常笑话等娱乐内容
  适用条件：偶尔娱乐；图文和视频是平台现状例子，不指定唯一格式
- 建议平台加强数据管理，避免向第三方出售个人数据
  适用条件：受访者称已习惯泄露，未提出具体应用内隐私设计；其泄露判断未经验证
- 即使接受一定数据分享，也不希望因此遭受明显损害
  适用条件：若发现损害可能诉诸法律只是应对策略；目前自述未明显受扰
- 加强处理重复营销的矩阵账号，减少无关内容刷屏
